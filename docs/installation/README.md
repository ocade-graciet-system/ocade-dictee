# Installer OCADE Dictée chez le client

| Système                         | Procédure                | Fichier à télécharger                                   |
| ------------------------------- | ------------------------ | ------------------------------------------------------- |
| macOS (Apple Silicon ou Intel)  | [macos.md](macos.md)     | `…_aarch64.dmg` (M1 et suivants) ou `…_x64.dmg` (Intel) |
| Windows 10 / 11 (64 bits)       | [windows.md](windows.md) | `…_x64-setup.exe`                                       |
| Linux (Ubuntu, Debian, Fedora…) | [linux.md](linux.md)     | `…_amd64.AppImage`                                      |

Téléchargement : https://github.com/ocade-graciet-system/ocade-dictee/releases/latest

Après l'installation : premier lancement (téléchargement du modèle, ≈ 512 Mo, une seule fois), puis test de dictée. Checklist support : [../support/checklist-5-minutes.md](../support/checklist-5-minutes.md).
